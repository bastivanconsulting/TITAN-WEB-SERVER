Bienvenue dans le Wiki officiel de **Titan Web Server**.

Titan Web Server est une solution moderne de serveur web et de reverse proxy, écrite en Go, conçue pour la performance, la sécurité et la simplicité d'opération.

## Pourquoi Titan Server ?

*   **Performance** : Écrit en Go, supportant HTTP/3 et QUIC nativement.
*   **Simplicité** : Configuration unique inspirée de NGINX, interface web intégrée pour l'administration.
*   **Résilience** : Clustering natif via Raft pour une haute disponibilité.
*   **Sécurité** : Gestion automatique des certificats SSL/TLS (Let's Encrypt), logs d'audit ISO 27001.
*   **Polyvalence** : Support des sites statiques, reverse proxy, et applications PHP (FastCGI).

## Fonctionnalités Clés

*   🚀 **HTTP/3 & QUIC** : Support protocolaire de dernière génération.
*   🔒 **SSL Automatique** : Intégration transparente de Let's Encrypt.
*   📦 **Clustering** : Synchronisation automatique de la configuration entre les nœuds.
*   🐘 **Support PHP** : FastCGI intégré pour servir des applications PHP.
*   🛠️ **API & UI Admin** : Contrôle total via une interface web ou une API REST sécurisée.
*   💾 **Mise en Cache** : Cache en mémoire et sur disque configurable.
